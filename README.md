# Online English Learning System V2
[![GitHub branch](https://img.shields.io/badge/Branch-dev-brightgreen.svg)](https://github.com/kina111/OnlineEnglishLearningSystem-V2/tree/dev)

## 🚀 Giới thiệu

**Online English Learning System V2** là một nền tảng học tiếng Anh trực tuyến toàn diện, được thiết kế cho việc học cá nhân. Bạn có thể tham gia các khóa học, làm bài tập, thi thử, hoặc tương tác với giáo viên và bạn bè — tất cả đều trên web.

📚 Một số điểm nổi bật:
- Hệ thống người dùng – phân quyền (Learner, Expert, Marketing, Admin)
- Quản lý khóa học, bài học, bài tập, và bài kiểm tra
- Tải lên tài liệu học tập (pdf, video, hình ảnh, file tài liệu)
- Báo cáo tiến độ học tập, thống kê điểm
- Quản lý đăng ký, thanh toán
- Nhắn tin, nhận tư vấn từ Expert, Marketing và trao đổi với các Learner khác.
- Quản lí Dashboard cho các vai trò tương ứng.

📚 Cách sử dụng
- Với Guess: Truy cập vào homepage, đăng ký / đăng nhập thông qua xác thực email.
- Với tài khoản Learner: nhận tư vấn, đăng ký khóa học, xem bài học, làm bài tập, thi thử, theo dõi tiến độ, trao đổi với bạn bè.
- Với tài khoản Expert: tạo bài học, bài tập, upload nội dung học.
- Với tài khoản Marketing: Tư vấn mua khóa học, thiết kế slider trên homepage.
- Với tài khoàn Admin: Quản lí người dùng, khóa học, doanh thu, ...
